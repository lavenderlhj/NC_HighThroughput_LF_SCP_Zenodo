README


This folder contains the Python scripts used to generate the calculations and 
visualizations reported in Figures 2-7 and the Supplementary Figures.

All required input files are included in the "Input" folder. 
The scripts use relative file paths, so the folder can be unzipped 
and run without changing the file paths.

[Folder contents]

- Input: input files required by the scripts
- output: files generated by the scripts
- CodeInventory.xlsx: list of scripts, input files, input-file sources, calculations, and corresponding figure panels
- Python files: scripts used for data analysis and visualization


[System Requirments]

No non-standard hardware is required. 
The scripts can be run on a normal desktop or laptop computer.

Tested operating system: Window 10/11
Tested Python version:3.10.11

Required Python packages are listed in: requirements.txt


[Installation]

Install Python and the required packages.
Open a terminal or Command Prompt in this folder and run: python -m pip install -r requirements.txt
Typical installation time: Approximately 5-10 minutes,depending on the computer and internet connection.


[Instruction for use]

The included input files are also used as demonstration data.
To run a script, open a terminal or Command Prompt in this folder and use:python ScriptName.py
The scripts generate numerical results and figure files, including SVG files, in the specified output folder.
Most scripts complete in approximately 5min on a normal desktop computer. 


[Outputs and figure preparation]

The scripts generate the calculations and data-derived plots used in the manuscript. 
Final figures were assembled from the generated SVG files. 
Manual editing was limited to figure layout, position, color, labels, and formatting. 
The underlying numerical results were not changed during figure preparation.
